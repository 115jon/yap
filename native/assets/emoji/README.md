# Emoji data

`emoji-15.tsv` is generated by `tools/build-emoji.mjs` from the
`@emoji-mart/data` 1.2.1 set 15 file (`sets/15/native.json`):

```
node tools/build-emoji.mjs <path to native.json>
```

One line per emoji in category order, tab-separated: category id, emoji id,
name, skins (`unified` values joined by `,`, default first), shortcodes
(space-joined, preferred first, ordered and sanitized as `src/lib/emoji.ts`
does), keywords, emoticons. The native strings are the `unified` code points.
It is embedded by `yap-core::emoji`.
